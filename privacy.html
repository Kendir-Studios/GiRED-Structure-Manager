Política de Privacidade - GiRED Fixer

O GiRED Fixer é uma extensão de produtividade desenvolvida para melhorar a navegação, organização e revisão de conteúdos nas plataformas GiRED.

Recolha de dados

O GiRED Fixer não recolhe, transmite ou vende dados pessoais dos utilizadores.

Armazenamento local

A extensão utiliza o armazenamento local do navegador (Chrome Storage) apenas para guardar preferências do utilizador, como o estado ativo da extensão e opções de visualização dos painéis.

Acesso às plataformas GiRED

A extensão funciona exclusivamente nas plataformas apps.gired.pt e cms.gired.pt. O acesso é utilizado apenas para adicionar melhorias de interface, códigos de estrutura SA/AT, ferramentas de pesquisa, filtros e funcionalidades auxiliares.

Partilha de dados

Nenhuma informação é enviada para servidores externos nem partilhada com terceiros.

Contacto

Para questões relacionadas com o GiRED Fixer, consulte o repositório oficial do projeto no GitHub.
